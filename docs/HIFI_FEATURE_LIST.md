## 3. 上传任务

### 3.1 上传任务总览

展示指标：

- 上传中任务数量
- 今日上传量

### 3.2 任务队列

任务展示内容：

- 文件名
- 文件大小
- 上传进度
- 并发数
- 上传链路或策略
- 当前状态
- 异常原因

任务状态：

- 上传中
- 限速中
- 完成
- 待重试
- 失败
- 已取消

### 3.3 大文件上传能力

- server-proxy 上传链
- multipart 上传
- 断点续传
- 后台入桶
- 上传会话恢复
- 失败重试

- 指数退避

### 3.4 任务操作

- 新建上传
- 清理完成任务
- 对失败任务一键重试
- 查看失败原因
- 取消上传任务

## 7. WebDAV 能力

高保真在设置中明确出现 WebDAV Basic Auth，因此需要纳入功能范围。

基础能力：

- WebDAV 访问开关
- Basic Auth 凭据配置
- 只读模式联动
- 支持 Cyberduck / rclone 使用

建议支持的方法：

- PROPFIND
- GET
- PUT
- DELETE
- MKCOL
- MOVE

只读模式下禁止：

- PUT
- DELETE
- MKCOL
- MOVE

## 8. 删除与回收站

### 8.1 普通删除

- 单对象删除
- 批量删除
- 删除前确认
- 批量删除二次确认

### 8.2 回收站模式

开启后删除对象前：

1. 复制对象到 `.trash/` 前缀
2. 确认复制成功
3. 再删除原对象

需要记录：

- 原路径
- 回收站路径
- 删除时间
- 操作来源
